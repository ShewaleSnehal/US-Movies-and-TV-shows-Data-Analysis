# US-Movies-and-TV-shows-Data-Analysis


## Project Overview

This project focuses on analyzing Movies and TV Shows data from major US streaming platforms such as Netflix, Prime Video, Hulu and Disney+. The main goal of this project is to understand viewer preferences, identify trending genres, compare platform-wise content availability and analyze IMDb ratings.

The project was developed as an end-to-end Data Analytics project using Python for data cleaning, transformation, analysis and visualization. Through this analysis, meaningful insights were generated about streaming trends, language preferences and platform performance.

---

## Problem Statement

The entertainment industry is growing rapidly with multiple streaming platforms competing to attract viewers. Each platform offers different types of content based on audience preferences.

The objective of this project was to:

* Analyze movies and TV shows available on US streaming platforms.
* Identify the most popular genres among viewers.
* Compare streaming platforms based on content availability.
* Understand the relationship between IMDb ratings and runtime.
* Analyze language preferences in streaming content.
* Generate business insights using data visualization.

# End-to-End Project Workflow

## 1. Data Collection

The first step was collecting the dataset containing information about movies and TV shows from multiple streaming platforms.

### Tools Used:

* Python
* Pandas

### Tasks Performed:

* Imported CSV dataset into Python environment.
* Checked dataset structure and columns.
* Explored rows, data types and missing values.

---

## 2. Data Cleaning & Preprocessing

Real-world datasets often contain null values, duplicate records and inconsistent data. Data cleaning was one of the most important stages of this project.

### Tasks Performed:

* Removed duplicate records.
* Identified missing/null values.
* Handled missing data using KNN Imputation technique.
* Standardized column formats.
* Converted data into suitable formats for analysis.
* Filtered unnecessary data.

### Libraries Used:

* Pandas
* NumPy
* Scikit-learn

This step helped improve the quality and reliability of the analysis.

---

## 3. Data Transformation

After cleaning the data, transformation techniques were applied to make the dataset ready for visualization and insight generation.

### Tasks Performed:

* Grouped data based on genres and platforms.
* Filtered records based on ratings and language.
* Extracted useful insights from large datasets.
* Created summarized tables for visualization.

### Objective:

To convert raw data into meaningful and understandable information.

---

## 4. Exploratory Data Analysis (EDA)

EDA was performed to discover hidden patterns, trends and relationships within the dataset.

### Analysis Covered:

* Platform-wise content comparison
* Genre popularity analysis
* IMDb rating analysis
* Runtime vs Rating analysis
* Language distribution analysis

### Libraries Used:

* Matplotlib
* Seaborn

Visualization helped in understanding viewer behavior and streaming platform trends more effectively.

---

## 5. Platform Analysis

A detailed comparison of streaming platforms was conducted to identify which platform offers the largest and most diverse content library.

### Key Insights:

* Prime Video had the highest number of movies and TV shows.
* Netflix focused more on quality-driven and original content.
* Hulu provided a balance of movies and TV shows.
* Disney+ mainly focused on family-friendly entertainment.

This analysis helped compare business strategies of different streaming services.

---

## 6. Genre & Viewer Preference Analysis

Genre analysis was performed to identify what type of content audiences prefer the most.

### Major Findings:

* Documentaries received the highest IMDb ratings.
* Comedy genres maintained strong viewer engagement.
* Drama content attracted a broad audience with balanced ratings.

This analysis showed how audience interests vary across genres.

---

## 7. Language Analysis

Language analysis was conducted to understand multilingual content trends across streaming platforms.

### Key Findings:

* English was the most common language.
* English-Spanish content was popular among bilingual audiences.
* English-French content supported international viewers.

The analysis highlighted the importance of multilingual content in the US entertainment market.
